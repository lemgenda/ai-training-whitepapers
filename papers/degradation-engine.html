1. Abstract

The LemGendary Degradation Engine (v16.4.1-MODERNIZED) is an industrial-standard synthetic image degradation and manifold derivation framework designed for Deep Learning Vision Restoration, Super-Resolution, and Artifact Removal pipelines. It unifies offline batch manifold derivation with real-time, on-the-fly training augmentation into a single, pure NumPy, SciPy, and Pillow execution engine. By deterministically simulating physical optical aberrations, atmospheric scattering, sensor noise electronics, precipitation dynamics, lossy compression artifacts, and analog film degradation, the engine synthesizes paired restoration datasets while recording exact per-sample quantitative parameter descriptors into structured JSON annotations for parameter-conditioned neural network supervision.

2. High-Velocity Optimizations & Physics Formulations

2.1 Physics-Based Kernel Formulations

The engine implements eight modular degradation kernels grounded in physical optics and signal processing:

  • Atmospheric Haze: Implements Koschmieder atmospheric scattering I(x) = J(x)t(x) + A(1 - t(x)) with depth-gradient variation.
  • ISOCalibrated Noise: Heteroscedastic noise modeling photon shot noise (Poisson) and sensor readout noise (Gaussian).
  • Directional Motion Blur: Linear convolution with rotated 2D line kernels.
  • Defocus Aperture Blur: Out-of-focus circular aperture disk filter.
  • Low-Light Starvation: Non-linear gamma curve darkening, shadow readout noise, and Kelvin temperature shifting.
  • Precipitation Dynamics: Wind-oriented rain streaks combined with droplet mist scattering.
  • JPEG DCT Quantization: 8x8 block discrete cosine transform quantization and 4:2:0 subsampling simulation.
  • Film Degradation: Analog grain, vertical emulsion scratches, dust particles, and saturation fading.

3. Hybrid Cloud & Registry Integration

Every synthesized sample pair is tracked in manifold_registry.db and annotated in labels/<split>/<name>.json with exact physical parameters (e.g., kernel length, angle, ISO variance, beta attenuation) enabling parameter-conditioned model training.

4. Multi-Modal & Format Resilience

Compiler image outputs are standardized to WebP:

  • Input / Degraded Images: WebP Lossy (Quality = 92)
  • Ground Truth Targets: WebP High-Fidelity (Quality = 95)
  • Segmentation / Alpha Masks: WebP Lossless

The DynamicOnTheFlyDegrader bridge allows the Model Training Suite to import and execute degradation kernels at runtime on clean images with zero duplicate code.

6. Synthesis Flow & Topology

Clean images are fed through DynamicDegrader, encoded via ImageTranscoder to WebP, logged into manifold_registry.db, and written atomically with structured parameter descriptors.

7. Unified Models Registry

Degradation manifolds feed downstream restoration heads including NAFNet (deblurring/denoising), MPRNet (multi-stage progressive restoration), MIRNet-v2 (low-light enhancement), FFA-Net (dehazing), DeblurGAN-v2, and DiffBIR.

8. Conclusion

The LemGendary Degradation Engine establishes a unified, deterministic, and physically accurate synthetic data generation system, eliminating code duplication across dataset compilation and model training.
