1. Abstract

The LemGendary AI Ecosystem is governed by three interoperable control planes: the AI Studio Desktop GUI (presentation tier), the Master CLI Suite (scripted pipeline dispatch), and the Master Sidecar API (asynchronous REST, WebSocket, and IPC services). This manual hub establishes the authoritative operating procedures, communication contracts, and error remediation pathways for operators running data synthesis, hyperparameter tuning, model training, and checkpoint validation across universal hardware.

2. Interface Control Boundaries

To eliminate developer friction and ensure system stability, every operator interface connects directly to dedicated, single-responsibility services:

3. Desktop GUI Operational Protocol

The AI Studio Desktop GUI serves as the primary visual cockpit for machine learning engineers. Built on Tauri v2 and React 18, it offers millisecond-latency UI updates without the memory penalty of traditional web containers.

  • Hardware Probing: Real-time detection of CUDA compute capability, MPS active allocation, and CPU thread headroom.
  • Dataset Synthesis: One-click visual trigger for manifold compaction, WebP zero-intermediate transcoding, and hardlink deduplication.
  • Training Orchestration: Real-time spatial ladder observation, loss curve plotting, and nuclear-hardened emergency checkpoint halts.

Detailed screen layouts and control dictionary mappings are provided in the AI Studio GUI Operator Manual and GUI Control Registry.

4. Unified CLI Dispatch Matrix

For headless, cloud, or scripting environments, the ecosystem exposes deterministic command-line utilities. These include lem-env for infrastructure management, lemtrain for model training, and python compiler.py for data compilation:

# Complete environment health verification
lem-env audit --strict

# Automated hardware discovery and CUDA probe
lem-env probe

# Launch training run for dedicated NAFNet deblurring model
lemtrain --model nafnet_debluring --precision fp16 --batch-size auto

Consult the Master CLI Operations Manual for exhaustive flag references and parameter specifications.

5. Sidecar Telemetry & IPC Protocols

The asynchronous daemon tier coordinates background execution across dedicated ports:

  • Environment Daemon (:8000): Health endpoints, package installation pipelines, and environment inspection.
  • Compiler Daemon (:8100): Dataset job dispatch, progress streaming, and manifold validation.
  • Training Daemon (:8200): Persistent ACID SQLite job queue, real-time WebSocket loss streaming (/api/ws/jobs/{id}/logs), and checkpoint commit notifications.

Complete route schemas, payload models, and WebSocket event structures are available in the Master API Manual.

6. Cross-Project Automation (CPA)

Cross-Project Automation guarantees that actions triggered in one repository (such as updating dependency manifests or finalizing a trained weight artifact) cleanly propagate throughout the entire ecosystem without manual re-linking or state desynchronization.

7. Conclusion

The Master Operations Manuals Hub establishes clear operational guidelines across all user-facing and programmatic entrypoints, ensuring deterministic execution from local developer workstations to cloud cluster deployments.
